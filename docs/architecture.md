# Architecture

`scripts/run_competition_batch.py` → argparse CLI → phased async batch runner → source adapters → one bounded HTTP fetcher → SQLite + content-addressed private blobs. Output is atomically replaced JSONL in original input order, plus JSON operations/coverage report and request-event log. Inputs never come from a hardcoded company list.

Identity is resolved for all inputs before enrichment. Optional frozen BRREG CSV/JSONL is streamed and hashed, retaining original CSV rows with deterministic typed extraction. Missing/malformed rows fall back to the exact live API. Invalid individual identifiers remain failed envelopes. Default balanced scheduling offers official accounts to every anchored company first, then runs website-only passes by source quality before optional role/workplace/group requests. This allocation favors feasible external evidence after baseline breadth. Per-company and whole-run caps are independent and explicit. `official-first` preserves explicit module order with equal per-company allotments.

Each HTTP start reserves a durable journal row before DNS. Robots, redirects, retries and failed DNS attempts consume the same cap. All DNS addresses must be public and the connection is pinned to the validated address using the locked httpcore backend; TLS still validates the original hostname. No proxy environment, socket destination, browser or search adapter bypasses that path. One in-flight request per host, bounded workers, host pacing, two-attempt retry limit, cooldown and recoverable circuit breaker bound load. Documents are bounded to 2 MB decoded, robots 256 KB; no remote code or instructions execute.

Pydantic validates claims/evidence. SQLite stores snapshots, observation versions, current profiles, run history, checkpoints, run configuration and request reservations. Blobs are SHA-256-addressed. Identical source values update last-checked without adding a new observation. File output occurs after every input is terminal; interrupted runs have SQLite checkpoints. Resume requires matching input/configuration and retains the original resource deadline/counter.

The viewer uses only the standard-library loopback HTTP server and read-only SQLite. It escapes external strings, disallows scripts/frames/remote assets via CSP, validates Host and exposes JSON rather than raw captured HTML. It is deliberately separate from the public HTTP client and never runs during evaluation. Package source and runtime require neither Docker nor paid services.

Revision 2: cold identity can use the documented exact-ID filtered endpoint in 25-ID chunks, preserving the complete original JSON response and each company's exact row pointers. Measured 100-ID responses sometimes exceeded the 15-second download bound; missing/failed chunks fall back to exact entity/subunit lookups. Parsed response documents are shared in memory to avoid reparsing a batch for every fact. Shared official-source cooldowns wait within the wall deadline instead of immediately starving all later identities.

Balanced enrichment now has separate website passes ordered by evidence quality: registry-listed URLs and name-compatible business-email domains, then a fair one-request official-role pass, then other source-derived business-email domains; guessed domains are disabled. Workplaces/group follow those passes. Source-quality ordering generates candidates only; publication requires collected exact organisation-number proof and either the full legal name or the documented four-signal legal-form/name/address policy. Same-run responses are deduplicated (128-entry bound), with shared_response_hits reported; every new run still rechecks live/conditional sources. Robots redirects share the fetched policy for its actual final origin. A URL alone no longer counts as substantive external enrichment.

Selected overnight configuration adds reversible expanded literal extraction and an adaptive navigation selector: missing categories receive one bounded page attempt, repeated populated categories are skipped. Contacts quoted for installers, dealers, groups or developers are quarantined. Descriptions require company-home/about context; product excerpts remain product scoped. Evidence-backed semantic retractions retain historical observations and are distinct from source outages, which preserve stale facts. No model or relaxed identity gate was introduced.

Coverage-cycle scheduling flags retain measured controls: external-first defers roles, coverage-fair makes a bounded fair candidate pass and recycles interrupted allocations once. Neither improved development company coverage, so the submitted configuration retains balanced allocation. The selected change is corroborated legal-form ownership proof with immutable literal name/org/street/postcode spans, plus mandatory conflict safety and no guessed domains. No financial parser or dependency changed.
