Enabled sources: documented public BRREG entity/subunit/roles/group APIs, the normalised annual-accounts API, optional frozen official registry snapshot, and bounded public company-site pages after exact identity validation. Identity data is attributed to Brønnøysundregistrene under NLOD 2.0. API documentation and dataset licence were checked on 15 October 2026. Relevant access URLs are in THIRD_PARTY_NOTICES.md and acquisition metadata.

BRREG's documented machine APIs explicitly permit automated access and are called under that published API policy. Its root `/robots.txt` disconnects HTTP clients; it is not used as an API authorisation prerequisite. Company-owned page crawling DOES require a successful robots determination for each origin, including redirect origins. 404/410 robots means no published exclusion; 2xx/304 is parsed; explicit refusal is blocked; unavailable/network-failed policy lookup is failed and no company page is fetched. No robots/authentication/block bypass is implemented. Platform denylist includes LinkedIn, Meta, Glassdoor, Indeed, Google/Bing search pages, TikTok and X/Twitter. Linked profiles are not crawled or published as independently verified identities.

Discovery uses registry-listed URLs, registry business-email domains and at most one deterministic legal-name .no hypothesis. These are candidates only. No paid search provider, browser session or search-results claims are used. The exact name AND checksum-valid organisation number must occur in collected identity text with no conflicting valid number before company-site facts can be published. Manager/accountant/group email domains commonly fail this gate. Ambiguity is preserved, never promoted by name ranking.

Public HTML and structured data are untrusted input, not instructions. Only deterministic extraction runs. Company-owned descriptions are attributed promotional statements, not sentiment or independent assessment. Generic industry labels remain industry facts and never become actual business descriptions. Private raw evidence is retained for local audit; no entire company page or roles response is redistributed. Public official-data exports exclude private birth dates/addresses and exclude company-site material whose redistribution rights have not been cleared.

Timeouts, 403/429/451, circuit breakers, URL blocks and incomplete resource-limited searches are recorded distinctly. No CAPTCHAs, login, paywall, unauthorised endpoint, personal credential or private reference answer is accessed. Responses at documented public endpoints may still be sparse or unavailable. BRREG 410 legal removals purge this company's cached observation/history with an identifier-only tombstone, unlike ordinary refresh failures. Full evaluator-supplied registry files are never altered; existing exported files are immutable run artefacts and should be removed/redacted by their custodian if a later legal withdrawal applies.
