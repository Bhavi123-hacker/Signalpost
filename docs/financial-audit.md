# Financial semantic audit — revision 2

The prior binding audit checked whether values resolve to source bytes; it did not establish accounting meaning. This revision additionally retrieved original filed accounts using the documented BRREG annual-account-copy endpoint. Actual PDFs are scanned; pypdf returned zero text. The assistant visually reviewed rendered original table images, rather than substituting OCR or model-generated numbers. This is a sample semantic check, not independent human adjudication or proof of every record.

Reviewed filings: Kolbjørn Olsen AS, Eines AS, Koan Appartement AS, Safety Guide AS, Isentrum Eiendom AS and Stiftelsen Birralee International School Trondheim (2025); Bovieran Veum AS (2025 negative result); Gjensidige Business Services Norge NUF (2023 SEK); Sydvaranger Drift AS (2024 USD); Helsepartner Nord-Norge AS (2025 standalone and consolidated group). Exact URLs, retrieval times, original PDF hashes, pages and observations are in artifacts/verification/revision2-financial-review.json. Covers were checked for organisation number, legal name and reporting period. NOK/SEK/USD table headers, whole amounts, explicit zero and negative signs were checked. Helsepartner's separate company and group tables demonstrate why scopes must not be merged; group notes explicitly specify whole numbers.

No amount or scale discrepancy was observed in the reviewed observations. This does not establish a corpus-wide error rate. `sumDriftsinntekter` means **total operating income**, including other operating income; it is not sales-only revenue. Each financial observation now carries an explicit metric definition. NUF is a Norwegian registration of a foreign enterprise, so its filed amounts cannot be described as Norwegian branch-only performance; entity kind and financial context now state this. Non-finite values and unknown explicit units are withheld. Missing amounts remain missing; explicit source zero remains a genuine observation.

The normalized API's OpenAPI does not annotate a universal scale guarantee. The reviewed originals corroborate whole currency amounts for the sampled NOK, SEK and USD records; all output retains the exact API decimal with scale=1 and no currency conversion. Other filings/periods are not independently PDF-audited. New unexpected explicit scale/unit metadata is quarantined. The parser never lets website text or a model repair an amount. If a future source discrepancy is found, withhold the affected interpretation and retain conflicting original observations.

The original archived BRREG field mapper assigns XML BigDecimal sums to the named result/assets/equity/debt fields directly. This helps document field meaning; the live originals provide the stronger sample-level semantic comparison. Failed PDF attempts are retained separately in private/revision2/financial-audit*/collected.json with their diagnostic counters. Several 15/60-second downloads timed out; the final bounded 120-second group attempt succeeded. These are separate audit requests, not hidden evaluator operations.

Optional reproduction: install requirements-audit.txt in an isolated environment, then run scripts/review_financial_filings.py with explicit input/output/state paths and --render. It collects original documents and marks them not_reviewed; it cannot automatically approve semantic correctness. pypdf 6.20.1 (BSD-3-Clause) and PyMuPDF 1.26.7 (AGPL-3.0, optional local rendering tool) are not imported by the default runner/viewer. Raw PDFs/images remain local because filings can include personal notes; reports expose only the necessary company-centric financial observations and access references.
